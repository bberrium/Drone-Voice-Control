КАК РАБОТАЕТ — ДЕТАЛИ РЕАЛИЗАЦИИ
🧠 Распознавание речи (recognizer.py)
01pyaudio открывает поток с микрофона (16kHz, mono)
02adjust_for_ambient_noise() — калибровка 2 сек при старте
03energy_threshold=4000 — порог для определения речи
04pause_threshold=0.8с — тишина = конец фразы
05Аудио → Google Speech API → текст строкой
06Текст кладётся в queue.Queue() для main цикла
07Всё работает в отдельном потоке (threading.Thread)
🚁 Управление дроном (controller.py)
01connect() → dronekit.connect(tcp:127.0.0.1:5760)
02Ждём is_armable: GPS fix + калибровка IMU
03mode = GUIDED → дрон слушает команды от ПК
04vehicle.armed = True → запуск моторов
05simple_takeoff(5) → взлёт, ждём altitude ≥ 4.75m
06send_velocity(vx,vy,vz) → MAVLink каждые 100мс
07При выходе: land() если is_flying, vehicle.close()

MAVLINK ПРОТОКОЛ И СИСТЕМА КООРДИНАТ NED
📡 Структура MAVLink пакета
СТАРТ
0xFE
ДЛИНА
N байт
SEQ
0-255
MSG ID
#84
ДАННЫЕ
vx,vy,vz

2 байта
▶MSG #84 = SET_POSITION_TARGET_LOCAL_NED
▶Маска 0b0000111111000111 — только скорость активна
▶DroneKit автоматически формирует правильный пакет
▶Отправляем каждые 100мс чтобы дрон не завис
▶Подключение: TCP (SITL) или USB/Radio (реальный дрон)
🧭 Система координат NED (авиационный стандарт)
vx +→ вперёд (North)
vx -→ назад
vy +→ вправо (East)
vy -→ влево
vz -→ ВВЕРХ ⚠️ (Down ось!)
vz +→ ВНИЗ ⚠️ (Down ось!)
⚠️ NED = North-East-DOWN: ось Z направлена ВНИЗ — это авиационный стандарт, не ошибка!

ВОЗМОЖНЫЕ ВОПРОСЫ НА ЗАЩИТЕ
Почему Python 3.10, а не новее?
DroneKit использует URLopener и другие API, удалённые в Python 3.11+. Версия 3.10 — последняя полностью совместимая.
Что такое режим GUIDED?
Режим Pixhawk где дрон принимает команды от внешнего компьютера через MAVLink. В отличие от STABILIZE (ручной) и AUTO (маршрут).
Почему vz отрицательный при движении вверх?
Система координат NED (North-East-Down) — авиационный стандарт. Ось Z направлена вниз, поэтому "вверх" = отрицательный vz.
Зачем threading и queue?
Распознавание речи блокирует поток. Threading позволяет одновременно слушать микрофон И управлять дроном. Queue — потокобезопасная передача данных.
Что такое армирование дрона?
Arming = запуск моторов на минимальных оборотах, готовность к взлёту. Перед армированием система проверяет GPS, батарею, IMU калибровку.
Какова задержка системы?
Google API: 500-2000мс (зависит от сети). Vosk offline: 100-300мс. Основная задержка — передача аудио в облако и обратно.
Как система понимает конец команды?
SpeechRecognition использует pause_threshold=0.8с. Если тишина длится 0.8 секунды — фраза считается завершённой.
Чем SITL отличается от реального дрона?
SITL симулирует физику, GPS и IMU программно. Отвечает на те же MAVLink команды. Подключение через TCP вместо USB/Radio.
